# A simple tree program
This is a simple CLI program targeted for Unix systems such as Linux, that prints out a tree of the desired directory and subdirectories. 
### Usage:
1. Compile using GCC. Example: `gcc tree.c -o customtree`.
2. Place the binary file in .local/bin or /usr/local/bin. (Be sure that your shell has a reference path to that directory!)
3. Run the binary file like so: `customtree [directory]` (if no directory is specified, the current working directory is printed).
4. Have fun!
